Telegram 频道批量归档器 —— 三步安装
====================================

【第一步】装 Python 与依赖
  1) 装 Python 3.9+，安装时勾选 "Add Python to PATH"
  2) 打开命令行，进到本目录：
       cd /d <本目录>
       python -m venv .venv
       .venv\Scripts\activate
       pip install -r requirements.txt
     国内网络慢可加： -i https://pypi.tuna.tsinghua.edu.cn/simple

     ★ cryptg 必须装上（关键，不是可选）：
       pip install cryptg -i https://pypi.org/simple
       清华等国内镜像常常没有 cryptg 的 Windows 轮子，会报
       "Could not find a version that satisfies the requirement cryptg"，
       所以这一条一定要显式指定官方源。
       验证：tgarchiver.py run 启动后第一行日志应有 crypto=cryptg x.y.z；
       显示 pyaes 就是没装，速度只有 1/100。

     若提示缺 python_socks，再单独跑：
       pip install "python-socks[asyncio]" -i https://pypi.org/simple

【第二步】填配置（两分钟）
  1) 打开 https://my.telegram.org ，手机号登录，API development tools 建应用
  2) 复制 .env.example 为 .env，把 api_id / api_hash 填进去
  3) 需要代理就填 TG_PROXY，例如 socks5://127.0.0.1:1080；直连留空
     注意：.env 是凭据文件，不要发给别人、不要提交到仓库

【第三步】登录并开下
  窗口 A（登录页）：
       python qr_server.py
  窗口 B（登录本体）：
       python login.py
  浏览器打开 http://127.0.0.1:47050/ ，手机 Telegram 扫码
  （二维码每 18 秒自动换新，随时扫都有效；也能用右侧手机号登录）

  登录成功后建任务并下载：
       python tgarchiver.py probe <频道名>
       python tgarchiver.py new --name demo --channel <频道名> --out "D:\Downloads\demo" --selector all
       python tgarchiver.py index demo
       python tgarchiver.py run demo

  另开窗口看速度：
       python monitor.py     ->  http://127.0.0.1:47060/

【可选】自动找代理（没节点时用）
   1) 采集：python tgproxy.py harvest --limit 120
      （默认读 4 个公开频道；也能 python tgproxy.py add "<你复制的 t.me/proxy 链接>"）
   2) 测活：python tgproxy.py test --limit 200
   3) 量速：python speedprobe.py --top 3 --bytes 3
   4) 选中一条写进 state/proxy.json：python tgproxy.py apply
      下载器下一轮重连就会用上，不用改 .env、不用重启

    ★更省事：开着 python monitor.py，页面下方「粘贴代理」框里一行一条贴
      t.me/proxy / t.me/socks 链接 → 点「添加并测活」→ 状态变「可用」后点
      「用这条」即切换，下载器下一轮重连生效。详见 README 5.7 节。
      下载器下一轮重连就会用上，不用改 .env、不用重启
   细节见 README.md 第 5 节。注意 ee 前缀（fake-TLS）与 webproxy 这类 Telethon 连不上，
   工具会标成「客户端专用」，要验证只能在官方 Telegram 客户端里试。

【常见问题】
  * 一直连不上：先 probe，确认 TG_PROXY 端口对、代理软件在跑
  * 报 database is locked：同一 session 被两个进程用了，只留一个 run
  * 速度一直红、只有几十 KB/s：先看日志里的 crypto= 是不是 cryptg。
    是 pyaes 就是没装 cryptg（装完快 112 倍），装了 cryptg 还慢才轮到换节点
  * 更多排错见 README.md 第 10 节

【停止】
  下载器 Ctrl+C 即可停；重跑同一条 run 命令会从断点继续。
